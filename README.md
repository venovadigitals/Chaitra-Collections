Chaitra Collections – Premium Ethnic Wear E-commerce Website

A modern, responsive e-commerce website for Chaitra Collections, showcasing handcrafted Indian ethnic wear including sarees, lehengas, kurtas, and blouses. Built using HTML5, CSS3, and Vanilla JavaScript, the project features a dynamic storefront powered by Supabase, along with a comprehensive admin dashboard for managing products, categories, customers, and orders.
